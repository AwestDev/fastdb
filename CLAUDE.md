# FastDbExplorer — AI entry point
**Read first: `docs/PROJECT_MASTER_CONTEXT.md`** (full handoff: rules, architecture, decisions, lessons, next feature).
Read-only WPF explorer for huge SQL Server databases. UI: Persian RTL, auto light/dark.
Commands: `dotnet build FastDbExplorer.slnx` · `dotnet test` · `publish.cmd` (offline portable build).
Hard rules: never run write SQL (`ReadOnlySqlGuard`); typed parameters only; **no plaintext passwords on disk** (a SQL password is entered in the profile form, stored only encrypted via DPAPI `ICredentialVault`, never shown again, no password popups — see `docs/CREDENTIALS.md`, which supersedes Master Context §2 rule 4); no SELECT * / DataTable / COUNT(*) on big tables; every View needs a code-behind with InitializeComponent.
